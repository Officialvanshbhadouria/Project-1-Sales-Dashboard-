<br>

🔄 Project Workflow

I followed a simple process while creating the dashboard:

Raw Data → Data Preparation → Pivot Tables → Charts → Slicers → Dashboard

First, I worked with the raw sales data and organized the required fields.
Then I created Pivot Tables to summarize the data and make it easier to analyze.

After that, I created charts from the Pivot Tables and connected different Slicers to make the dashboard interactive.

Finally, I arranged everything into one main dashboard so that the sales data could be understood visually.
